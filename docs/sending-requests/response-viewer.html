Response Viewer

After sending a request, the response panel shows the full server response with status, timing, body, headers, and more.

Status Bar​

The status bar at the top of the response panel shows key metrics. Each element is interactive.

Status Badge​

Shows the HTTP status code (e.g., 200 OK) with color coding:

  • Green — 2xx success
  • Blue — 3xx redirects
  • Orange — 4xx client errors
  • Red — 5xx server errors

Hover to see a description of the status code (e.g., "Request successful. The server has responded as required.").

Response Time​

Shows total response time in milliseconds or seconds.

Hover to see a timing waterfall breakdown:

  • DNS Lookup — domain name resolution
  • TCP Handshake — connection establishment
  • TLS Handshake — SSL/TLS negotiation (HTTPS only)
  • Waiting (TTFB) — time to first byte
  • Download — response body transfer
  • Total — end-to-end time

Each phase shows a colored bar proportional to its duration.

Response Size​

Shows the response body size.

Hover to see a detailed breakdown:

  • Response Size — headers + body
  • Request Size — headers + body (when available)

Network Info (Globe Icon)​

Shows network and TLS connection details.

Hover to see:

  • HTTP Version — 1.0, 1.1, or 2.0
  • Remote Address — server IP and port
  • TLS Protocol — TLSv1.2, TLSv1.3, etc.
  • Cipher — encryption cipher used (e.g., TLS_AES_128_GCM_SHA256)
  • Certificate CN — server certificate common name
  • Issuer — certificate authority
  • Valid Until — certificate expiry date

Click the copy icon in the popup to copy all network info as plain text.

All popups stay open when you move the mouse to them, so you can select and copy text.

Toolbar​

The toolbar provides quick actions:

IconAction
SearchOpen the search bar to find text in the response body
Wrap LinesToggle word wrapping in the response body
DownloadSave the response body to a file
BookmarkSave as an example (for saved requests)
CopyCopy the entire response body to clipboard
TrashClear the current response

Response Tabs​

Body​

Four view modes for the response body:

ViewDescription
PrettySyntax-highlighted, formatted view (JSON, XML, HTML). Includes line numbers, code folding, and bracket colorization
RawPlain text view with optional search highlighting
PreviewRendered HTML preview in a sandboxed iframe
TableTabular view for JSON arrays — sortable columns, up to 500 rows

Right-click in the Pretty or Raw view to Set as Variable — select any text and save it directly as an environment, collection, or global variable.

Headers​

Shows all response headers in a key-value table. Some headers have an (i) info icon — hover to see a description of what the header does.

Also shows request headers that were sent (auto-generated headers like Content-Type, User-Agent, etc.).

Tests​

Shows test results from post-response scripts:

  • Pass/fail summary with progress bar
  • Individual test results with green checkmark or red X
  • Error messages for failed assertions

When no tests exist, an empty state shows a "Generate Tests" button:

  • Creates a basic test template using the current response's status code
  • Runs the tests immediately against the current response
  • Switches to the post-response script editor so you can customize

Code​

Generates code snippets for the current request in 30+ language/library combinations (cURL, Python requests, JavaScript fetch, Go, Ruby, PHP, and more).

Cookies​

Shows all cookies set by the server via Set-Cookie headers in a table with columns: Name, Value, Domain, Path, Expires, HttpOnly, Secure, SameSite.

Response History (Clock Icon)​

The clock icon next to the response tabs shows a dropdown with the last 10 responses for the current saved request.

Each entry shows:

  • Timestamp — "Today, 5:02 AM" or "Mar 24, 3:15 PM"
  • Status code — color-coded (green/orange/red)
  • First entry is labeled "Current"

This lets you quickly compare recent responses without switching to the full History tab.

Search​

Click the search icon or press Ctrl+F to open the search bar. Type to search within the response body:

  • Shows match count in real-time
  • Highlights matches in the Raw view
  • Press Escape to close

Schema Change Detection​

When viewing the History tab, Rostyman automatically detects when the response JSON structure changes between runs. A banner shows:

  • Added fields — new keys in the response
  • Removed fields — keys that disappeared

This helps catch API breaking changes early.
