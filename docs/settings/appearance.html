Appearance

Themes​

Rostyman includes 20 built-in themes plus support for custom themes. Select a theme in Settings → Appearance or open the Theme Manager from the sidebar.

Font Size​

Change the base font size for the entire application:

SizeBest for
13pxCompact — more content visible
14pxSlightly compact
15pxComfortable
16pxDefault — recommended for most displays

Font size is applied immediately and saved for next launch.

Interface Font​

Choose the font used throughout the Rostyman interface — menus, labels, panels, and all non-code text. Select from 10 built-in options in Settings → Appearance → Interface Font:

  • System Default
  • Inter
  • Roboto
  • Open Sans
  • Lato
  • Nunito
  • Source Sans Pro
  • IBM Plex Sans
  • Fira Sans
  • Work Sans

Editor Font​

Choose the monospace font used in code editors, request/response bodies, scripts, and anywhere code is displayed. Select from 10 built-in options in Settings → Appearance → Editor Font:

  • System Default (monospace)
  • Fira Code
  • JetBrains Mono
  • Source Code Pro
  • IBM Plex Mono
  • Cascadia Code
  • Inconsolata
  • Ubuntu Mono
  • Roboto Mono
  • Hack

Language​

Rostyman is available in 18 languages out of the box. Change the language in Settings → Appearance → Language:

LanguageLanguage
EnglishDeutsch (German)Italiano (Italian)Bahasa Indonesia
Español (Spanish)Français (French)Nederlands (Dutch)Tiếng Việt (Vietnamese)
Português (Portuguese)日本語 (Japanese)Polski (Polish)Türkçe (Turkish)
中文 (Chinese)한국어 (Korean)Русский (Russian)العربية (Arabic)
हिन्दी (Hindi)ไทย (Thai)

The language change takes effect immediately — no restart required.

Language Manager​

Need a language that isn't included? Open the Language Manager to add or edit custom translations. You can create a new language pack or modify an existing one to better suit your needs.
