Cloud Storage

Rostyman is local-first by default, but you can optionally connect cloud storage providers to share collections with teammates. Cloud Storage supports Google Drive and Dropbox.

Connecting a Provider​

  1. Open Settings > Cloud Storage
  2. Click Connect next to Google Drive or Dropbox
  3. A browser window opens — sign in and grant Rostyman access
  4. Once authorized, a green checkmark appears next to the provider name

You can connect both providers simultaneously. Each connection is independent.

Sharing a Collection​

Once a provider is connected, you can share any collection:

  1. Right-click a collection in the sidebar
  2. Select Share to Cloud
  3. Choose your connected provider (Google Drive or Dropbox)
  4. Rostyman uploads the collection as a .rostyman file to a Rostyman folder in your cloud drive
  5. A shareable link is automatically generated and copied to your clipboard

Send this link to any teammate who uses Rostyman.

What Gets Shared​

  • All requests (method, URL, headers, params, body, auth)
  • Folder structure
  • Collection-level variables
  • Environments and environment variables
  • Pre-request and post-response scripts

What Does NOT Get Shared​

  • Vault secrets — never uploaded for security reasons
  • Request history — stays local to each user
  • Personal settings — themes, editor preferences, etc.

How Teammates Import Shared Links​

When a teammate receives your shared link:

  1. Click the link — if Rostyman is installed, it opens the app and starts the import automatically
  2. Or paste the link — go to File > Import, select the URL tab, paste the link, and click Import
  3. The collection appears in their sidebar, ready to use

If the teammate doesn't have Rostyman installed, the link opens the cloud provider's download page where they can save the .rostyman file and import it manually.

Auto-Sync​

After sharing a collection to the cloud, Rostyman keeps it synchronized:

  • Automatic upload — when you save changes to a shared collection, the cloud copy is updated
  • Sync status — visible in the collection's right-click menu (Synced, Syncing, or Conflict)
  • Notifications — you receive a notification when sync completes or encounters an issue

Conflict Resolution​

If the cloud copy has been modified by another user while you also made local changes:

  1. A notification alerts you to the conflict
  2. Open the collection's context menu and choose Resolve Conflict
  3. Pick whether to keep your local version or accept the cloud version

Managing Connections​

In Settings > Cloud Storage, you can:

ActionDescription
ConnectLink a new Google Drive or Dropbox account
DisconnectRemove the connection (shared collections remain in the cloud)
View synced collectionsSee which collections are currently shared to each provider
Revoke accessRemove Rostyman's permissions from your cloud account entirely
Check quotaSee available storage space on the connected provider

Sharing Workflow Example​

Here's a typical workflow for sharing with a teammate:

  1. You create and test a collection of API requests
  2. Right-click the collection > Share to Cloud > Google Drive
  3. Copy the generated link and send it via Slack, email, or any messenger
  4. Your teammate clicks the link — the collection appears in their Rostyman
  5. You update a request and save — the cloud copy updates automatically
  6. Your teammate gets a Source Watching notification and clicks Sync Now

Tips​

  • Cloud Storage is completely optional — Rostyman works fully offline without it
  • You can share the same collection to multiple providers
  • For version-controlled collaboration, consider Git-Native Storage instead
  • Shared collections work alongside local collections — no migration needed
